# PEREGRINE: notes for Claude Code

Study abroad and visa consultancy site for PEREGRINE (Tirana), built by DuaDev. See README.md for commands and layout.

- **Content source**: the client's FINAL Word documents in `instructions/` (Home, About us, Universities and Pathways, Boarding Schools, Seasonal Camps, Viza Turistike, Partner With Us). Their copy is loaded by `src/seed/`. The Claude Design prototype in `instructions/peregrine-handoff/prototype/` is the layout and component reference only; its copy is older.
- **Stack**: Next.js 16 App Router, Payload CMS 3.92 (Postgres adapter, Neon), Tailwind v4 (`@theme` in `src/app/(frontend)/globals.css`), zod, lucide-react.
- **Every section is a Payload block**: config in `src/blocks/configs.ts`, component in `src/blocks/components/`, registered in `src/blocks/RenderBlocks.tsx`. Components hold no copy. After changing fields: `npm run generate:types` and `npm run migrate:create <name>`.
- **Colour rule** (client feedback, 30 Oct 2026): brand colours only, navy + light blue + white (`instructions/color-palette.jpeg`); no champagne/gold. Use `text-sky-deep` for light-blue accent text on light backgrounds; plain `sky` is decorative there, `sky-light` is for text on navy. The admin still stores the old values `ivory` (now light blue `bg-mist`) and the button variant `champagne` (now white on navy). No colour pickers or free styling in the admin.
- **Layout rule** (same feedback, reference oxaliseducation.com): compact, minimal sections that fit on one screen; Blueprint Method as six stages in a row; FAQ in two columns. Section-by-section scrolling on desktop (`src/components/SectionScroll.tsx`): one wheel notch, swipe or key press moves one section, on screens 1024px and wider only; phones and tablets scroll freely (client request, 4 Nov 2026). A section is scaled down only if that makes it fit (no less than 80%); otherwise it keeps its size and gets extra stops. Side photos (`fit-media`) are capped to the screen height and cropped from the bottom instead of shrinking the text. Off only on pages with the booking form or rich text. New sections should fit at 1440x900. Client feedback is in `instructions/FEEDBACK.docx`; `npm run feedback:apply` wrote it to the database.
- **Languages**: English at `/`, Albanian at `/sq` (`redirects`/`rewrites` in `next.config.ts`, `[lang]` route; no proxy/middleware, so pages are served from the CDN without a function). Page copy is localized in Payload; fixed UI text lives in `src/lib/dictionary.ts` (both languages, same keys, tested). Server components get the language from `getRequestLocale()`; links go through `resolveHref(link, locale)` / `localizePath`. New English seed copy needs an Albanian entry in `src/seed/data/sq.json`, then `npm run translate`.
- **Copy rules**: no em-dashes (house style; a field validator enforces it on headings). Never add testimonials, ratings, partner logos, success rates or guarantees. Visa and admission decisions belong to the authorities; keep that wording.
- **Guardrails** (tested in `tests/`): legal notices are Owner-only, images need alt text and a confirmed licence before a page can be published, core pages cannot be deleted and their slugs are locked.
- Do not deploy, buy services or pick hosting without DuaDev's approval.
